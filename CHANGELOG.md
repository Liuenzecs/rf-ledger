# Changelog

All notable changes to this project will be documented in this file.

The format is based on Keep a Changelog and this project follows Semantic Versioning.

## [0.1.0] - 2026-03-02

### Added

- Local-first desktop bookkeeping app powered by Tauri + React + SQLite.
- Transaction CRUD workflow: add, list, filter, edit, and delete.
- Dashboard statistics with backend SQL aggregation.
- Backup workflow: automatic daily backup and manual backup from Settings.
- CSV export with UTF-8 BOM for Excel compatibility.
- Internationalization support (Chinese/English).
- Production build pipeline for Windows release executable.
